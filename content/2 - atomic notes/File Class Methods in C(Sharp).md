# File Class Methods in C(Sharp)

```cs
Create()                 - creates file
CreateText()             - creates text file
Delete()                 - deletes file
Exists()                 - bool for folder existing
GetCreationTime()        - returns DateTime object
GetLastWriteTime()       - returns DateTime object
Move()                   - moves a file to the specified location
```

To use file class, you must use `system.IO.File` or you can import it with `using system.IO` then you can just use `file` class.
