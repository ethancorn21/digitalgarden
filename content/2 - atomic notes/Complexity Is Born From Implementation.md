# Complexity Is Born From Implementation

Complexity is born from the implementation of solutions to solves problems. Anything not scoped to the solution of the problem, and instead is created as a piece for the deployment of the solution is complexity.

When we over engineer something we are adding complexity into a system. When we lose sight of value adds and begin to create just to create, we are adding complexity into a system. 

Complexity is inevitable in any system, but you should aim to keep it to a minimum. Focus on how your architecture forces complexity as a work around for slack in the design.
