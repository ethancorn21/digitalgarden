# Ship of Theseus

At what point does something become something else? The Ship of Theseus had all of it's wood replaced, was it still the same ship as before?

If we look at the ship as a system of components, interconnections, and purpose as Donella Meadows would say a system is composed of. She would also say that the system would remain the same system as long as the interconnections and purpose of that system remains the same.

So as long as the purpose of the ship is to sail, and it's way of sailing remains the same. Then we can say it is the same ship. A systems components change constantly. Wood rots, it must be replaced. New sails are added. Furniture is changed. Crewmen are changed. But the ship is fundamentally still the same ship no matter what components change.
