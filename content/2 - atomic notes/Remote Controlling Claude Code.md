# Remote Controlling Claude Code

You can remotely control Claude Code from your phone. Simply start a new session in desired directory:

`ethan@Ethans-MacBook-Pro digitalgarden % claude remote-control "session name"`

Now connect through Claude mobile app and now you can direct Claude on your Mac across the world.

Use case:
- directing Claude to work on the digital garden while on lunch at work
	- mitigates having to brink work & personal laptop on site
