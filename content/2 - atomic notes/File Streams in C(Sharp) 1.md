# File Streams in C(Sharp)

Streams are how programs get data from files. They allow programs to: 
- Read - read file
- Write - write to file
- Seek - find
- Flush - forces buffer to disk, does not close the file

Streams consists of input to the application, and outputs.
- Console.Out - standard output stream
- Console.In - standard input stream

File processing classes:
StreamReader
StreamWriter
FileStream
