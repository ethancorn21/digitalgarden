# Multi-Factor Authentication (MFA)

*port CCNA MFA over for whatever is not covered*

4 common factors of authentication:
- knowledge - something you know
- possession - something you have
- inherent - something you are
- location - somewhere you are

Balance between convenience and security

How MFA code is generated:
virtual MFA:
- AWS takes secret key and other info (device type, application, etc.) and combines them to generate a qr code. The qr code is scanned and placed into an authenticator app.
