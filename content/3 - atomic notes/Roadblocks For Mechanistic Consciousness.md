# Roadblocks For Mechanistic Consciousness

In order for AI to begin to "feel" the same way a conscious human does, we must first start with breaking down what that means.

What is a feeling? Does any one person feel the same way as any other person? I would wager not, but we associate the different feelings with the same label. Plato tried to answer this with his "World of Forms". The labels that we put onto the world are the imperfect reflection of a perfect reality. So we know that an object made of wood, with stick like objects attached to the main structure is a tree, but how do we know it's not a chair?

How do we know that a robot is feeling the same way that a person does? I suspect that we would simply have to describe how "feeling" feels for every single person and every single variation of feeling, and then see if an artificial intelligence has the capacity to feel in that same way, or rather the interpretation of that feel.

What mechanisms in humans cause us to feel? Obviously we have pain receptors and nerves that send electrical signals to our brain that can cause unbearable feelings. What mechanism could AI implement to cause that. Why would they stoop so low to copy biological implementations rather than create a new implementation purpose built for the artificial soul?
