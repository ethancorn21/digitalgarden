# Value vs Cost expenditure

Buying something based on the excised gain it will give you. Spending $100 to make $300 later on, versus spending $50 to make $100, saving $50.

Don't falter to face value. The value is greater for one of the decisions, yet the cost is also greater. Think not in costs, but in value gained.
